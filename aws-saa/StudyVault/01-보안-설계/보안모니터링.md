# 보안 모니터링 서비스

## CloudTrail

- **누가 무엇을 언제**: AWS API 호출 **감사 로그**
- 기본: 90일 보관 (이벤트 히스토리)
- Trail 생성: S3에 영구 저장 + CloudWatch Logs 전송 가능
- **관리 이벤트** (기본 활성): Create/Delete/Modify 작업
- **데이터 이벤트** (추가 설정): S3 객체 수준, Lambda 호출

> [!tip] 무결성 검증
> CloudTrail 로그 파일 무결성 검증 활성화 → SHA-256 해시

## AWS Config

- **리소스 설정 변경 추적** + 규정 준수 평가
- Config 규칙: 리소스가 규칙을 준수하는지 자동 평가
- 자동 수정: SSM Automation으로 비준수 리소스 자동 교정

> [!important] CloudTrail vs Config
> CloudTrail: "누가 변경했나?" (API 호출자)
> Config: "무엇이 변경되었나?" (설정 상태)

## Security Hub

- **중앙 보안 대시보드** (여러 서비스 통합)
- GuardDuty, Inspector, Macie, Config 결과 통합
- CIS 벤치마크, PCI DSS 규정 준수 점수

## Inspector

- EC2, Lambda, ECR 컨테이너 이미지 **취약점 자동 스캔**
- CVE(Common Vulnerabilities and Exposures) 기반
- 에이전트 기반 (EC2) 또는 에이전트리스 (Lambda)

## Access Analyzer

- **외부에 공개된 리소스 탐지** (S3, IAM 역할, KMS, Lambda 등)
- 의도치 않은 공개 액세스 감지
