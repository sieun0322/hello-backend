# Phase 2 — 인터랙션 태스크

> [← 프로젝트 계획](../PLAN.md)
> 선행 조건: Phase 1 완료

## 목표

3D 뷰어를 풍부하게 만들어 실제 포장 과정을 직관적으로 확인할 수 있게 한다.

---

## 1. 상품 클릭 → 정보 표시

> 참고: [viewer3d.md](../spec/viewer3d.md#2-상품-클릭--정보-표시)

- [ ] `ItemMesh`에 `onPointerDown` 이벤트 추가
  - 클릭 시 해당 상품 정보를 선택 상태로 설정
  - hover 시 외곽선(outline) 또는 밝기 강조
- [ ] `InfoOverlay.tsx` 구현
  - `@react-three/drei`의 `Html` 컴포넌트 사용
  - 표시 항목: 상품명, 크기(W×D×H), 무게, 박스 내 위치(x,y,z)
  - 클릭된 상품 위치에 고정, 카메라 회전 시 따라다님
  - 빈 공간 클릭 시 오버레이 닫힘

**검증:** 상품 클릭 → 정보 패널 표시, 다른 상품 클릭 시 교체, 빈 공간 클릭 시 닫힘

---

## 2. 상품 숨기기/보이기 토글

- [ ] 뷰어 우측에 상품 목록 패널 추가
  - 각 항목: 상품 색상 인디케이터 + 이름 + 눈 아이콘(👁)
  - 숨겨진 상품은 목록에서 반투명 처리
- [ ] `visibleIds: Set<string>` 상태 관리
  - 토글 버튼 클릭 시 Set에서 추가/제거
- [ ] `ItemMesh`에 `visible` prop 연결
- [ ] "전체 보이기 / 전체 숨기기" 버튼 추가

**검증:** 특정 상품 숨기기 → 씬에서 사라짐, 다시 토글 → 나타남

---

## 3. 단계별 포장 애니메이션

> 참고: [viewer3d.md](../spec/viewer3d.md#4-단계별-포장-애니메이션)

- [ ] 애니메이션 컨트롤 바 추가
  ```
  [ ▶ 재생 ] [ ⏸ 일시정지 ] [ ↺ 처음으로 ]   속도: [0.5x] [1x] [2x]
  ```
- [ ] `visibleCount` 상태 (0 → items.length)
  - 재생 중: `setInterval`로 속도에 따라 +1
  - 일시정지: interval 정지
  - 처음으로: `visibleCount = 0`
- [ ] 상품 등장 시 위에서 떨어지는 간단한 진입 애니메이션 (`useSpring` 또는 `useFrame`)
- [ ] 현재 배치 중인 상품 강조 표시

**검증:** 재생 시 상품이 순서대로 하나씩 등장, 일시정지/재생 토글 동작, 속도 조절 동작

---

## 4. 박스 전환 개선

- [ ] 박스 전환 시 fade 애니메이션 (이전 박스 fade-out → 새 박스 fade-in)
- [ ] 박스 선택 UI 개선
  - 현재 박스 번호, 박스 이름, 무게(현재/최대), 공간 활용률 표시
  - 키보드 방향키(←→)로 전환 지원
- [ ] 포장 결과 요약 패널
  - 총 박스 수, 전체 무게, 평균 공간 활용률

**검증:** 박스 3개 결과에서 전환 애니메이션 확인, 키보드로 전환 가능

---

## 5. UX 개선

- [ ] 빈 상태 화면 처리
  - 박스 프리셋 없음 → "박스를 먼저 등록하세요" 안내
  - 상품 프리셋 없음 → "상품을 먼저 등록하세요" 안내
  - 포장 결과 없음 → "주문을 구성하고 계산하세요" 안내
- [ ] 포장 불가 상품 경고 UI 개선
  - 경고 카드에 해당 상품 목록 + "이 상품보다 큰 박스가 필요합니다" 안내
- [ ] 로딩 상태 처리
  - 계산 중 버튼에 스피너 표시 (상품 많을 경우 체감 딜레이)

**검증:** 각 빈 상태 화면 수동 확인, 포장 불가 상품 경고 표시 확인
